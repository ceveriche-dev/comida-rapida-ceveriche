# 🍔 Comida Rápida Ceveriche

Aplicación web para la gestión y venta de productos de comida rápida, desarrollada como proyecto de portafolio para demostrar habilidades en desarrollo de software.

## 🚀 Características

- Visualización de productos de comida rápida.
- Interfaz web para los clientes.
- Gestión de productos y pedidos desde el área administrativa.
- Conexión con una base de datos para gestionar la información.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Node.js
- Express
- MySQL
- Git y GitHub

## 📁 Estructura del proyecto

- `index.html`: estructura de la página web.
- `styles.css`: estilos y diseño visual.
- `script.js`: funcionalidades del frontend.
- `server.js`: servidor y rutas del backend.
- `imagenes/`: imágenes utilizadas en los productos.
- `package.json`: dependencias y configuración del proyecto.
